# /tips-update

Web検索で最新のAI活用事例を収集し、Tipsを追加するスキル。

## トリガー

- `/tips-update`
- `Tips更新して`
- `新しいTipsを追加して`

## 処理フロー

1. **現状確認**
   - 各カテゴリのTips残数を確認
   - 残り少ないカテゴリを優先

2. **情報収集**
   - Web検索で最新AI活用事例を収集
   - 検索クエリ例:
     - エンジニア: `エンジニア AI活用 事例 2026 生産性`
     - コンサル: `コンサルティング AI活用 事例 2026 戦略`
     - バックオフィス: `バックオフィス AI活用 事例 2026 効率化`

3. **Tips作成**
   - 収集した事例をTips形式に整形
   - フォーマット:
     ```json
     {
       "id": "eng-XXX",
       "category": "engineer",
       "title": "【事例】〇〇社：△△で□□を実現",
       "content": "📊 実績: ...\n\n説明...\n\n💡 ポイント:\n- ...\n\n🎯 ...\n\n🔗 参考: URL",
       "tags": ["タグ1", "タグ2"],
       "created_at": "YYYY-MM-DD",
       "used_count": 0
     }
     ```

4. **確認・追加**
   - 作成したTipsをユーザーに確認
   - 承認されたらdata/tips.jsonに追加
   - コミット・プッシュ

## Tips作成のポイント

### タイトル
- `【事例】` または `【実践】` で始める
- 具体的な数字・成果を含める
- 例: `【事例】LINEヤフー：Copilotで1日2時間の工数削減`

### 本文構成
```
📊 実績/効果（数字で示す）

説明文（2-3文）

💡 ポイント/今日から使える方法:
- 箇条書きで3-5点

🎯 行動を促すメッセージ

🔗 参考: URL
```

### カテゴリ別のトーン
- **engineer**: 技術的な具体性、ツール名を明記
- **consultant**: ビジネスインパクト、ROIを強調
- **backoffice**: 日常業務との関連、専門用語を避ける

## 出力例

```
📊 Tips残数確認:
- engineer: 38件
- consultant: 28件
- backoffice: 27件

🔍 consultantが少ないため、コンサル向け事例を検索します...

【事例】デロイト：AIで監査業務を40%効率化
📊 実績: 年間監査時間を40%削減、品質向上も実現
...

このTipsを追加しますか？
```
