# Slack短縮投稿テンプレート

## 基本フォーマット

```
{カテゴリ絵文字} 今日のAI Tips

💡 {1行Tips（30文字以内）}

📖 詳しくはこちら → {Notionリンク}

---
📰 今日のAIニュース
• {ニュース1}
• {ニュース2}
```

---

## カテゴリ別絵文字

| カテゴリ | 絵文字 |
|---------|--------|
| エンジニア | 👨‍💻 |
| コンサルタント | 📊 |
| バックオフィス | 📋 |

---

## 記入例

### エンジニア向け
```
👨‍💻 今日のAI Tips

💡 Copilotのコメント→コード生成、日本語でもOK

📖 詳しくはこちら → https://notion.so/xxx

---
📰 今日のAIニュース
• GitHub Copilot、新機能追加
• OpenAI、GPT-5の噂
```

### コンサルタント向け
```
📊 今日のAI Tips

💡 競合分析、AIで2時間→15分に短縮できる

📖 詳しくはこちら → https://notion.so/xxx

---
📰 今日のAIニュース
• Claude、企業向けプラン拡充
• Perplexity、日本語強化
```

### バックオフィス向け
```
📋 今日のAI Tips

💡 経費精算の確認、AIに任せると見落とし激減

📖 詳しくはこちら → https://notion.so/xxx

---
📰 今日のAIニュース
• Microsoft Copilot、Excel連携強化
• freee、AI機能を追加
```

---

## Tips

- **1行Tipsは「結果」を書く**: 「〜できる」「〜が変わる」
- **数字があると刺さる**: 「2時間→15分」「3倍速く」
- **ニュースは2件まで**: 多すぎると読まれない
- **Notionリンクは必ず入れる**: 興味ある人の導線
