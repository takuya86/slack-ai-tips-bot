## カテゴリ別ルール

### consultant
- ビジネスインパクト（ROI・コスト削減効果）を数字で示す
- 戦略的な視点を含める
- 💡ラベル: 「提案に使えるポイント」
- タグ例: McKinsey, BCG, AI戦略, DX, ROI

### backoffice
- 日常業務との関連を明確にする
- 専門用語を避けてわかりやすく
- ステップバイステップで説明
- 💡ラベル: 「自社でも試せるポイント」
- タグ例: 経理, 人事, 法務, チャットボット, 自動化

### engineer
- 技術的な具体性を重視
- ツール名・コマンドを明記
- コード例やプロンプト例を含める
- 💡ラベル: 「今日から使えるポイント」
- タグ例: Claude, GitHub Copilot, CI/CD, コードレビュー

### tools
- 特定AIツール（Claude, Cursor, Cowork, Gemini, ChatGPT等）の具体的な活用事例
- 業種を問わない汎用的な使い方 or 業種別の活用例
- 「このツールでこうやったらこうなった」という実体験ベース
- 設定方法・プロンプト例・ワークフロー例を含める
- 💡ラベル: 「今日から試せるポイント」
- タグ例: Claude, Cursor, Gemini, Cowork, ChatGPT, プロンプト, ワークフロー

## 品質基準

1. タイトルに具体的な数字・成果を含める
2. 出典URLは実在する公開ページであること（必須）
3. 「今日から使える」具体的なアクションを記載
4. 2025年〜2026年の最新事例を優先
5. 重複する企業・事例を避ける

## 重要

- 各Tipsの間に `---SEPARATOR---` を必ず入れてください
- frontmatterの `---` とSEPARATORを混同しないでください
- 出典URLは架空のものを使わないでください
