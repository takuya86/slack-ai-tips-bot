# Tips追加ガイド

Tips（AI活用ヒント）の追加方法と効果的な書き方をまとめています。

## Tips追加の流れ

1. `data/tips.json` を編集
2. 新しいTipsを追加
3. コミット・プッシュ
4. 次回の定期実行で配信対象になる

## Tipsのフォーマット

```json
{
  "id": "eng-004",
  "category": "engineer",
  "title": "【事例】〇〇社：△△で□□を実現",
  "content": "📊 実績: ...\n\n説明文...\n\n💡 ポイント:\n- ...\n\n🎯 ...\n\n🔗 参考: https://...",
  "tags": ["タグ1", "タグ2"],
  "created_at": "2026-01-26",
  "used_count": 0
}
```

### 各フィールドの説明

| フィールド | 必須 | 説明 |
|-----------|------|------|
| `id` | ◯ | ユニークID（例: eng-001, con-001, bo-001） |
| `category` | ◯ | `engineer` / `consultant` / `backoffice` |
| `title` | ◯ | タイトル（40文字以内推奨） |
| `content` | ◯ | 本文（詳細は下記） |
| `tags` | ◯ | タグ配列（RSS記事のフィルタリングに使用） |
| `created_at` | ◯ | 作成日（YYYY-MM-DD） |
| `used_count` | ◯ | 配信回数（新規は0） |
| `prompt` | - | コピペ用プロンプト（あれば） |

### IDの命名規則

- エンジニア向け: `eng-001`, `eng-002`, ...
- コンサル向け: `con-001`, `con-002`, ...
- バックオフィス向け: `bo-001`, `bo-002`, ...

## 効果的なTipsの書き方

### 1. タイトル

**良い例:**
- `【事例】LINEヤフー：Copilotで1日2時間の工数削減`
- `【実践】議事録作成を5分で終わらせる方法`

**避けるべき例:**
- `AIの使い方` （具体性がない）
- `ChatGPTについて` （メリットが不明）

### 2. 本文の構成

```
📊 実績/効果（数字で示す）

説明文（2-3文で簡潔に）

💡 ポイント/今日から使える方法:
- 箇条書きで3-5点
- 具体的なアクションを記載

🎯 行動を促すメッセージ

🔗 参考: URL（出典を明記）
```

### 3. 数字を入れる

**良い例:**
- 「作業時間30%削減」
- 「年間44.8万時間を削減」
- 「2週間→2分で完了」

**避けるべき例:**
- 「大幅に効率化」
- 「かなり便利」

### 4. すぐ使えるアクションを示す

**良い例:**
```
💡 今日から使える方法:
1. ExcelデータをCSVでエクスポート
2. Claude/ChatGPTに貼り付け
3. やりたいことを日本語で伝える
```

### 5. コピペ用プロンプトを追加（任意）

```json
{
  "prompt": "以下のデータについて、部門別の月次売上合計を算出してください。\n\n[データを貼り付け]"
}
```

## カテゴリ別のトーン

### エンジニア向け (`engineer`)

- 技術的な具体性を重視
- ツール名・コマンドを明記
- コード例やプロンプト例を含める

### コンサル向け (`consultant`)

- ビジネスインパクトを強調
- ROI・コスト削減効果を数字で
- 戦略的な視点を含める

### バックオフィス向け (`backoffice`)

- 日常業務との関連を明確に
- 専門用語を避けてわかりやすく
- ステップバイステップで説明

## タグの付け方

タグはRSS記事のフィルタリングに使用されます。関連記事が優先表示されます。

**推奨タグ:**
- ツール名: `Claude`, `ChatGPT`, `Copilot`, `Cursor`
- 業務: `議事録`, `経費精算`, `コードレビュー`
- 効果: `生産性向上`, `自動化`, `時短`
- 種別: `事例`, `実践`, `活用法`

## 注意事項

- JSON形式が壊れないよう注意（カンマ、括弧）
- 本文内で `"` を使う場合はエスケープ（`\"`）するか、`『』` を使用
- 出典URLは必ず記載（信頼性向上）
- used_countは0で追加（配信されると自動でインクリメント）

- [ ] カテゴリが正しいか
- [ ] タイトルに具体的な数字や成果が入っているか

- [ ] タグが適切か
