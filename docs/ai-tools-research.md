## NotebookLM

### 概要
Googleが提供する資料分析AI。PDFやドキュメントをアップロードし、その内容に基づいてQ&Aや要約が可能。

### 業務別活用例

#### コンサルタント
- **競合分析の効率化**: 競合5社の年次報告書分析を8時間→1時間に短縮（87.5%削減）
- **提案書作成支援**: 提案書作成を3時間→45分に削減（75%削減）
- **市場調査・リサーチ**: 競合サイトのWeb記事や製品情報から競合分析やFAQ作成

#### 人事・労務
- **就業規則QAボット**: 就業規則、経費精算マニュアルを学習させ、社員からの質問に自動回答
- **新入社員オンボーディング**: 社内ルールや業務手順をAIが教育担当として機能

#### 経理
- **経費精算ルール確認**: 申請方法を即座に説明し、問い合わせ対応を削減
- **請求書処理サポート**: 支払い方法や締め日対応の手続きを迅速に確認

#### 総務
- **契約書比較検討**: 複数契約の秘密保持条項などを横断的に抽出・比較
- **社内ナレッジ管理**: ベテラン社員のノウハウを学習させ、誰でもアクセス可能に

#### 営業事務
- **製品仕様QAボット**: 製品仕様書を基にQ&Aボットを作成し、顧客対応効率が2倍に
- **議事録自動作成**: 音声データから要点・決定事項・担当者・期限を自動整理

### すぐ使えるプロンプト例

#### 議事録作成

**基本的な議事録**
```
会議の音声データと資料をもとに、会議名、日時、参加者、議題ごとの要点（議論の内容と決定事項）、全体のまとめを構造化して出力してください。
```

**タスク抽出型**
```
会議内のタスクをすべて抽出し、「タスク内容」「担当者」「期限」「優先度」「備考」の表形式で整理してください。
```

**要約型**
```
会議に参加していなかった人でも3分以内で把握できるように要約してください。専門用語には補足をつけ、具体的な数字は省略せず、800文字程度に収めてください。
```

**ネクストアクション型**
```
次回の会議で議論すべき「持ち越し事項」「報告事項」「新規検討事項」を出力し、そのまま次回の会議招集通知に使える形式にしてください。
```

#### 長文PDF理解

**概要把握**
```
資料の内容を200字程度で要約してください。それを詳細に理解するために全体を主要な要素で区切ってそれぞれに見出しを付け、見出し毎に200字程度で説明してください。
```

**キーワード抽出**
```
この資料の重要なキーワードを30個抽出し、抽象度順に並べて、それぞれ簡潔に説明してください。
```

**理解度チェック**
```
この資料の内容を理解するための問題を表形式で30個作成してください。問題と回答を含めてください。
```

### 無料版の制限
- ノートブック数: 最大100個
- ソース数: 各ノートブックに最大50個（それぞれ最大50万語）
- チャットクエリ: 1日あたり50件まで
- 音声生成: 1日3回まで
- ファイルサイズ: PDFは1つあたり最大32MB程度

## Gamma / Canva AI

### Gamma

#### 概要
テキストからプレゼンテーション・ドキュメント・Webページを自動生成するAIツール。

#### 業務別活用例

**営業・コンサルタント**
- **提案書作成**: 1行のテキストからプレゼンテーションの叩き台を自動生成
- **不動産提案書**: 物件情報を登録するだけで売却提案書を数分で作成

**総務・人事**
- **社内報告資料**: 会議資料や社内報告書を数分で作成
- **チーム協働**: リアルタイム共同編集機能で複数人での校正作業を効率化

#### Tips・コツ

**プロンプトの具体性が重要**
- NG例: 「マーケティング戦略について」
- OK例: 「2025年Q2のデジタルマーケティング戦略と予算計画、KPI設定を含む日本語プレゼンテーション」

**AIっぽさを排除する**
- 生成された資料はあくまで「叩き台」として扱う
- 自社の思想・哲学、顧客への具体的な提案を追加

#### 注意点
- 無料: 初回400クレジットのみ、透かしあり
- 有料: Plusプラン月1,200円（年払い）

### Canva AI

#### 概要
デザインツールCanvaに搭載されたAI機能。Magic Design、Magic Write、AI画像生成など。

#### 業務別活用例

**人事・採用**
- **求人募集チラシ**: 17,942点の採用テンプレートから選択
- **SNS採用広告**: Instagramストーリー等で職場の雰囲気を発信

**経理・財務**
- **月次売上レポート**: スプレッドシート連携でMagic Chartsで可視化
- **インフォグラフィック作成**: 1-2時間→10-15分に短縮

**総務・バックオフィス**
- **社内マニュアル**: ChatGPT×Canvaで内部文書を効率的に作成

#### Tips・コツ

**ChatGPTとの連携**
- ChatGPTで構成・文章を作成 → Canvaでビジュアル化
- インフォグラフィック作成時間を85-90%削減

**AI機能は英語で使う**
- Magic Design等のAI機能は英語入力推奨
- 日本語で作成後、翻訳で対応

#### 注意点
- 無料: AI画像生成50回、AI動画生成5回まで
- 有料: Proプランで回数制限解除

## 会議・議事録AI

### ツール比較表

| ツール | 特徴 | 無料枠 | 日本語対応 | おすすめ用途 |
|--------|------|--------|------------|------------|
| **tl;dv** | 無制限の文字起こし | 無制限（3ヶ月保存） | 30言語以上 | Zoom/Meet連携 |
| **Otter.ai** | 英語に特化した高精度 | 月300分（1回30分） | 対応（精度課題） | 英語会議 |
| **Fireflies.ai** | 多言語対応（100言語超） | 800分（3回まで） | 対応 | CRM連携 |

### 選定フローチャート

```
利用言語は？
├─ 英語メイン → Otter.ai（精度重視）
├─ 日本語メイン → tl;dv or Fireflies.ai
└─ 多言語混在 → Fireflies.ai

無料で使い続けたい？
├─ YES → tl;dv（無制限、3ヶ月保存）
└─ NO → 月の利用時間で判断
```

### 効果
- 従来: 1時間の会議から議事録作成に2〜3時間
- AI活用後: 数分で完了、議事録作成工数を90%削減

## ChatGPT / Claude

### ChatGPT 業務活用事例

#### コンサルタント向け

**提案書・企画書作成**
```
あなたは企画書作成のプロフェッショナルです。
以下の要件で企画書の目次構成を作成してください。

#企画概要
[企画の概要を記載]

#ターゲット
[対象となる顧客層]

#必要な要素
- 現状分析
- 課題設定
- 解決策
- 実施計画
- 期待効果
```

**市場分析・競合調査**
```
あなたは優秀なマーケティングコンサルタントです。
[業界名]業界の市場分析を実施し、以下を含めて報告してください：
- 市場規模とトレンド
- 主要競合3社の強み・弱み
- ターゲット顧客のペインポイント
- 成長機会の提案
```

#### バックオフィス向け

**求人広告作成**
```
[職種名]の求人広告を作成してください。
条件：
- 経験年数: [X年]
- 必須スキル: [スキル一覧]
- 勤務地: [場所]
- 魅力的で簡潔な文章で400字以内
```

**Excel関数作成**
```
労務部門で使用する勤怠管理シートをExcelで作成したいです。
以下の機能を含めてください：
- 有給休暇残数の自動計算
- 月次勤務時間の集計
- 必要な関数の説明
```

### Claude 業務活用事例

#### コンサルタント向け

**長文分析・要約**
```
以下の文書を読んで、最も重要な結論を3つ、箇条書きで要約してください。
各項目は150字以内で、専門知識のない読者にも分かりやすい表現で。

[文書を添付またはペースト]
```

**プレゼン資料構成**
```
あなたはプレゼン資料作成の専門家です。
[クライアント名]向けの提案資料を10～15枚のスライド構成で作成してください。

テーマ: [テーマ]
含めるべき要素:
- 現状課題
- 解決策
- 導入効果（ROI試算）
- 実施ステップ
```

**議事録作成**

以下の会議メモから、議事録を作成してください。
含める項目：
- 日時・参加者
- 議題ごとの要約
- 決定事項
- アクションプラン（担当者・期限付き）

[会議メモ]
```

**業務マニュアル作成**
```
あなたは業務マニュアル作成の専門家です。

対象読者: 新入社員
